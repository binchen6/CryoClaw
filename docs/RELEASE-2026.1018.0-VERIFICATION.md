## 审查与修复

- 工作区路径校验、真实路径边界与原生目录授权独立于渲染器；修复文件系统根目录子项误拒绝。编辑采用内容哈希冲突检查和同目录临时文件换装，链接不能作为普通文件覆盖。
- 附件缩略图检查扩展名、真实路径、读取规则、文件大小与头部像素预算；前端串行生成并丢弃已移除附件的结果。
- 主题包只接收注册属性与有界数值，不执行 HTML/CSS 选择器/脚本或远程资源。Bearer 本地接口有请求大小和时间限制；主题 IPC 校验窗口，循环响应和发送失败不会抛出主进程异常或泄漏等待槽位。
- 代理只覆盖固定官方服务目标；登录凭据由内核维护。账户与模型请求按连接/会话隔离。真实账户和代理测试状态不进入版本库。
- 更新器在安装器确实启动后退出；旧卸载失败先进入恢复流程。此前安全快照中的两项中等风险已整改；快照扫描的范围与结论仍以当次记录为准，不把测试通过表述为安全无缺陷证明。
- 修复模型分工保存成功提示被配置快照清除、配置刷新导致折叠状态丢失；修复 Windows 时间轻微超前导致备份去重失效。移除未使用的归档操作状态字段。
- 全页检查发现头像 metadata 请求缺少 HTTP 认证，已复用共享/设备凭证回退并限定同源头像端点；本机头像图像通过鉴权 fetch 转为对象 URL，跨网关或切换 Agent 的迟到结果不会覆盖当前头像。凭证范围回归覆盖与实际安装版网络验证均通过。
- 预载串行调度、合并相同页面任务，隐藏/离线/生成中跳过；滑块按帧合并更新。动效使用浏览器原生机制，无需增加 Rust 与渲染器间通信路径。
