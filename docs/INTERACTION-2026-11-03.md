# 展开、菜单与工作空间交互审查

本轮沿实际渲染模板扫描展开/收起、`details`、`aria-expanded`、原生 popover 与手动菜单，逐项核对触发器、定位、返回方向、卸载时机、键盘及 reduced-motion。初始清单含 73 处模板/接线记录（含重复绑定和说明，不等于 73 个独立控件）。共同约束已写入 `CLAUDE.md` 与 `design-guidelines-zh.md`。

## 审查与实现

| 范围 | 处理 |
|---|---|
| 工作空间、Dock 文件预览 | 两处共用打开方式组件；移除共享 CSS anchor 名，使用原生 invoker 与视口定位，点击打开者再次关闭，选择项目后关闭；搜索/编辑聚焦使用统一字段令牌 |
| 原生自动浮层 | 用量、上下文、模型选择、Dock 新标签、浏览器更多、文件打开方式、看板更多接入共享 invoker 定位与同边进出；保留业务自身事件与原生 light-dismiss |
| 会话项菜单 | 共用 `placePopover()`，上/下翻转、视口夹取；滚动和窗口变化重新定位；既有键盘、两阶段退场与代次保护保留 |
| 会话列表更多 | 保留已有面板裁剪边界下的相对定位与两阶段退场；这是滚动面板内菜单，不能直接把视口坐标当作父坐标 |
| 输入区加号/权限、分支、技能、命令候选 | 手动菜单共用测量定位；进入与退出沿触发边，退场内容不可交互；技能与命令候选通过共享存在期管理延后移除；过期命令不拦截键盘 |
| Provider 模型分组菜单 | 补位置夹取、点外部关闭、Esc 回焦、退出帧与重开代次保护 |
| 看板更多、标签右键 | 更多菜单改为原生 popover；标签菜单补反向退场和边信息，保留已有看板卡片 morph/iframe 生命周期 |
| 原生折叠区 | 设置（订阅、模型路由、代理、记忆、高级参数、主题、QQ）、扩展分组、工具参数/输出、思考、命令任务、上下文报告、Git 目录、浏览器标注详情等共用 `details::details-content` 双向尺寸与可见性过渡 |
| 受控懒折叠区 | 工具组、单工具卡、进度卡、会话看板、Dock 目录树、记忆召回/正文/梦境/创建表单接入共享指令；首次折叠不求值内容，收起后释放子树；快速重开取消旧移除任务，重复流式更新不延长退出截止时间 |
| Provider 分组 | 保留已有 grid 1fr/0fr、inert 与稳态不裁剪菜单的实现 |
| 历史图片 | 在同一图片节点上以实际图片高度作展开上限，尺寸双向过渡；无窗口/对象 URL 迁移 |
| Dock/工作空间调宽 | 鼠标移动只更新布局，释放后才提交持久化；缓存容器宽度，补失去窗口焦点与卸载清理；取消调宽插值，去掉 Dock 重复边框，分隔线与会话列表同样细线/渐隐/命中宽度 |

例外：系统 select 与文件选择器保持系统行为；停靠的会话信息面板不当作按钮菜单；toast、原生 dialog、看板展开卡保留各自的淡出/morph/焦点契约；任务长错误正文的截断切换是文本呈现；画布选择轮廓属于编辑反馈。没有把未配置的外部渠道连接成功、未运行的平台或其它内核版本写成已验证。

## QQ 配置修复

腾讯 QQ 2.0 的私聊访问策略和原生命令审批名单是两个维度。内核要求顶层与各账号的 `allowFrom` 非空，并禁止 `*`；旧界面在 `dmPolicy=open` 时追加 `*`，造成保存拒绝，遗留配置也可能阻断后续启动。

保存与腾讯插件启动迁移现在清理通配符，保留显式名单；空审批名单使用内核保留的非匹配哨兵 `openclaw:approval-disabled`。开放私聊由 `dmPolicy=open` 单独表达，不扩大命令审批权限。扫码没有操作者 OpenID 时同样写入非匹配哨兵。填写小写/带前缀的会话标识时先在表单提示格式问题，避免提交已知无效的配置。凭据、禁用状态和其它高级字段沿用既有合并逻辑。

最终安装版完整 UI 96 场景/11 截图通过，真实聊天随机码回复持久化、同客户端对象重连后的历史/会话/输入可用均通过，renderer 异常为零。实际工作空间与 Dock 菜单、字段聚焦和调宽在常规窗口及 800px 深色窗口分别通过，截图位于 `out/ui-release/startup-1103/workspace/` 和 `workspace-narrow/`。专项测试最初未等待视觉就绪而发生一次开关断言失败；已补用共享 `waitForVisualReady()`，保留原生事件/节点诊断及二次点击关闭断言，完成稳定页面和窄窗复核，不把首次失败直接认定为产品缺陷。启动严格同配置对照、资源指标和剩余启动中退出长尾见 [启动验收](STARTUP-2026-11-03.md)。本轮仅本地候选，未公开发布或推送。
