## 实现与兼容边界

TypeBox 1.3.34 的 703 个 build 文件在离线打包时合并为 17 个共享 ESM 文件，保持九个公开入口、函数名称、跨入口引用身份、Format 注册与编译/解释校验行为。只接受固定 manifest、导出映射及完整源码指纹；未知版本、未知源码和 API 形态保留上游布局。打包先运行原版/收敛版对比 smoke，更新器只复用经校验配方，不携带编译器。仅操作离线暂存树；中断恢复/损坏/路径逃逸/rename 失败回滚有回归。可用 CRYOCLAW_COMPACT_TYPEBOX=0 构建原布局。

网关 hello 后先完成可见历史和首轮会话列表，再启动辅助目录/卡片读取；断连会取消旧连接后续读取。ticker 停止/重开隔离代次，旧请求 finally 不会解锁或阻塞新轮次。主进程 ready 通知只唤醒传输退避，不替换正在连接或进行身份/profile 准入的 socket；手动重试语义保留。

实际安装验证覆盖当前 Windows x64 及当前内核；未知版本走保守回退有自动测试，不等同于已实机测试其它内核、macOS 或 ARM64。工厂锁保留各目标平台可选依赖图。
