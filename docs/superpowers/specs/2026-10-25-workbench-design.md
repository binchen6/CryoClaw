## 看板

参考录屏的模板选择、预览、创建、详情编辑、自由布局和模型制作流程。保留已有 iframe、SDK、本机状态和任务边界，新增按需添加模块的模板库，避免每次都创建整套示例。

标签页右键菜单只有“编辑看板详情”“删除看板”。详情包含标题、说明；打开菜单不改变当前看板，操作明确绑定右键所在标签。模型每次编辑读取最新说明。键盘菜单键/Shift+F10 与鼠标右键等价，Escape 关闭并恢复焦点。

编辑模式提供布局整理和内容定位：选中整张卡片，或在沙箱 iframe 内指向具体元素；选中只定位、不执行原按钮、不发模型请求。共享输入显示当前目标并允许清除。发给模型的上下文包含 boardId、cardId、可定位的 CSS 选择器、元素文本及看板说明；修改其他模块、状态、布局需要用户明确要求。退出编辑、切换标签或删除目标时清除过期选区。

收敛入口：顶部“让模型制作”负责输入；“编辑布局”只负责整理和选择，不再隐式打开同一个输入框。归档显示只读态和恢复入口；保存过程不丢弃快速连续调整。详情修改不刷新 iframe，不触碰卡片本机状态。
