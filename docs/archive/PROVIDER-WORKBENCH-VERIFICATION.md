# 模型设置工作台重构验收

## 范围与设计

依据本轮三张模型设置参考图，将原先混排的设置内容拆为供应商目录、供应商详情、添加供应商三层。沿用 CryoClaw 的 MiSans、CryoBlue、语义主题 tokens、原生图标和克制的浅灰曲面，不引入新依赖。

- 目录：订阅/托管与 API 供应商分区、整行入口、协议/认证/默认状态、模型数量、主模型概览、供应商/模型搜索。
- 详情：清楚呈现实际连接信息、安全密钥编辑、模型 ID/上下文/显示名表格、同步/新增/能力配置/默认/删除入口。
- 添加：可换行的预设 chips、自定义端点、原有 OAuth/API key/模型选择链路、固定可达的底部操作区。
- 角色、备用模型、智能体映射、账户/用量、自定义分组和排序保留在可展开高级区，不删除原有能力。
- 标识、协议和代理端点是实际配置的只读展示，不伪造供应商重命名，不将本地代理误作普通 URL 改写。密钥留空保留原凭据，取消或离开页面清理草稿。

设计记录：[模型设置工作台](../../documents/designs/provider-workbench.md)。

## 代码审查修复

- 分离密钥验证锁与 `config.patch` 锁，修复验证成功却被自身 busy 拦截的问题。
- 密钥保存独立操作 token；失败可重试，成功清理秘密，再次编辑仍可保存；reset 后迟到的验证/sidecar 响应不修改新表单。
- 在线模型拉取捕获预设与请求 token，阻止旧结果串入其他供应商或解开新请求的锁。
- 添加保存捕获表单数据与生命周期，阻止离页后的旧验证继续提交或覆盖新表单状态。已发送的补丁不会被虚假宣称为撤销。
- 视觉复核统一密码框与其他输入高度；添加底栏补偿设置滚动容器的底部留白，避免底栏下露出表单字段。
- 全部预置供应商使用统一 24×24 手绘 CryoIcons，16px 预设入口也可辨识；别名和已知自定义端点复用同一图标族，未知自定义供应商显示名称首字母。无运行时图片请求或新增依赖。

## 验证方式与边界

实际构建产物通过隔离 Electron 夹具验证：全新临时 profile、禁止 HTTP(S)/WS(S)、专属空闲端口与 UUID 目标校验；只模拟只读 RPC/IPC，禁止 `config.patch`、真实凭据验证和真实账户操作。

UI 覆盖 1440/800/600 宽度 × 浅色/深色：目录、普通详情、长 ID/端点详情、预设添加、自定义添加，共 30 个场景；另验证搜索、返回、能力抽屉取消、密码默认隐藏/空值、连接信息只读、保存默认禁用、底栏和末尾字段可达、无横向溢出及 renderer exceptions。

异步保存/拉取使用生产处理函数与配置控制器的内存 VM 回归，覆盖成功、失败、重复、连续编辑、切换/重置、sidecar 及迟到 finally；不调用真实服务。
