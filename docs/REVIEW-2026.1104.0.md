# 2026.1104.0 深度审查补充

延续[上一轮人工审查](REVIEW-2026.1103.0.md)和[全局交互扫描](INTERACTION-2026-11-03.md)，本轮重点追踪安装版真实启动、OpenClaw10.10契约、技能发现和退出所有权。历史结果不作为最终安装包的验收证据。

| 范围 | 已处理的问题与保留边界 |
|---|---|
| 原生启动与缓存 | 旧主线程编译缓存触发第二层Gateway，导致父IPC和性能采样指向启动器。遵循10.10原生handoff，主线程关闭缓存、worker继续启用；同步Windows栈参数。PID必须为端口实际所有者且是应用持有的独立Node。 |
| 正常退出 | 接受原SIGTERM后只对应用自己的IPC通道unref，保留原生清理句柄和期限。真实子进程异步清理后自然exit0有回归；应用exit0不能替代网关exit0。 |
| 失效补丁 | 七处由上游接管的补丁退役，检查上游ownership、预算和生命周期合同；旧命令缓存不再绑定10.10失效的私有导出。未知旧内核保留原生路径。详情见[内核审查](KERNEL-2026.10.10.md)。 |
| 数据与回退 | Agent25→27、state20→22遵循原生Doctor恢复备份。更新/回退物理目录前读取目标源码准入上限和当前数据库版本，覆盖已提交WAL；不兼容时拒绝换装，不覆盖或回退用户数据。 |
| 技能发现 | 默认取消每分钟全量重扫，保留显式watch偏好；每次启动到实际可用后延后刷新一次。活动生成暂缓，旧连接取消未执行任务，已执行任务不随重连重复。安装/卸载/更新/导入和手动操作仍能主动发现变更。 |
| 技能读取 | 页面和引用菜单共用单次在途读取，变更按代次失效；120秒与原生预算一致，15秒提示慢刷新并保留原内容。旧核仅在明确拒绝refresh字段时回退旧参数；权限、超时错误不被吞掉。 |
| 交互与焦点 | 工具卡片改用全局focus-visible，指针点击不增加焦点环，键盘使用共享令牌。11组真实Electron专项验证覆盖菜单边界、往返动效、反转、窄屏、输入聚焦、直接调宽与reduced-motion，已人工查看截图。 |
| QQ | 继续校验多账号、旧通配符DM语义、独立命令审批哨兵、扫码取消和凭据主进程所有权。最终QQ隔离UI通过；10.10安装资源的实际host schema校验状态见发布记录。 |
| 构建与供应链 | 工厂图冻结，TypeBox1.3.35固定源码/API/共享身份后离线703→17模块。fs-safe保留精确0.26.5，撤回没有合格收益证据的0.26.15试验。 |

四层完整回归2916通过、6跳过、0失败（`.cache/release-1104-tests-post-ready.log`，23539ms）。前端生产依赖公告0；根工具图15中危、网关工具图33中危，无high/critical。未对冻结内核依赖做未经验证的跨主版本覆盖。
