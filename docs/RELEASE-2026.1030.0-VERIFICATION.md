启动阶段构成（内核 `OPENCLAW_GATEWAY_STARTUP_TRACE=1`，10 插件）：`process.bootstrap` 16.6 s、`sessions.projection` 3.6 s、`plugins.runtime-post-bind` 23.3 s（其中 tavily 15.2 s、openclaw-weixin 5.4 s、feishu 注册 1.4 s）、`sidecars.main-session-recovery` 26.4 s 与其并行。下一步若要继续压缩，应优先处理这三个全局插件的加载路径与主会话恢复，而不是渲染层。
