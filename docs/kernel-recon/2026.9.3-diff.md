# OpenClaw 2026.9.2 → 2026.9.3 差异取证（只读，不改内核）

> 方法：npm 下载两版 tarball 解包（`.cache/kernel-recon-93/v92|v93` + fs-safe 0.8.1/0.8.5 + 7 个 vendored 插件包），
> dist 做 registry/结构/关键函数比对；补丁命中经真实 npm install 树（gw92/gw93）实跑
> `scripts/lib/kernel-dist-patch.js` 验证；CLI 矩阵经 Electron-as-Node（24.18.1）实测。
> 结论先行：**协议层纯增量（RPC +6 / -0，chat delta 逐字节一致，扩展/技能目录零变化）——
> 硬阻断集中在两处：Node engine 剔除 22 线（捆绑 runtime 22.23.2 打包与 CLI 双双失效）与
> dist chunk `.js`→`.mjs` 翻转（补丁扫描漏打 peer-link 与 windowsHide）**；fs-safe 六个 asar
> 注入点在 0.8.5 逐字节同形态、实跑全命中，补丁本体无需改动。

## 1. 运行环境（Breaking — 硬阻断）

| 项 | 2026.9.2 | 2026.9.3 | 影响 |
|---|---|---|---|
| Node engine | `>=22.22.3 <23 \|\| >=24.15.0 <25 \|\| >=25.9.0` | **`>=24.16.0 <25 \|\| >=26.1.0`**（Node 22/25 剔除） | 捆绑 runtime 22.23.2 双重失效：① 打包/升级期 npm PATH 前置的 `node` 被 preinstall 拒绝（实测：`requires Node >=24.16.0 <25 \|\| >=26.1.0, detected Node 24.14.0`）；② Windows 交互 CLI（resolveCliNodeBin→runtime/node.exe）被 `openclaw.mjs` 运行时守卫 `process.exit(1)` 拒绝。动因：旧 Node SQLite TEXT 截断（数据损坏级，不可绕过）。**Electron 43.4.0 内嵌 Node 24.18.1（实测）满足**——gateway/CLI-exe/updater 冒烟不受影响 |

**适配**：`package.json` `cryoclaw.node` 22.23.2 → **24.21.0**（2026-09 最新 24.x，ABI 137 与 Electron 43 内嵌 24.18.1 同线）。

## 2. dist 结构（Breaking — 补丁扫描面）

- dist 根 chunk **`.js` → `.mjs` 翻转**：v9.2 根 5503 个 `.js`；v9.3 根 275 个 `.js` + 5380 个 `.mjs`
  （`method-scopes-*`、`plugin-peer-link-*`、`payload-verification-*`、`server-chat-*`、ws `client-*` 均变 `.mjs`）。
  `dist/entry.js` 仍在（package-resources install-skip 与 updater 校验不受影响）；子目录清单不变（新增 `native-hook-relay/`，仅 624B 纯 JS 轻量入口）。
- **补丁实跑结论（真实 npm install 树）**：
  - fs-safe 0.8.1→0.8.5：root-file/pinned-open/regular-file/file-identity 六个注入点**逐字节同形态**；
    `patchAsarBoundaryCheck`=4 文件、`assertAsarBoundaryCoverage`=PASS、`patchFsSafeAsarUnpacked`=1。**kernel-dist-patch.js 补丁本体零改动**。
  - peer-link 补丁 8/9：`auditOpenClawPeerDependency`/`linkOpenClawPeerDependency` 签名不变，但住进
    `plugin-peer-link-*.mjs` → 现行只扫 `.js` 的候选收集**漏打**，且 coverage 断言只查 fs-safe root-file.js、
    **不会兜出此漏**（R56 级静默缺口：asar 模式下带 peerDependencies.openclaw 的 vendored 插件审计失败 → 启动拒绝 ready 风险）。
  - windowsHide：v9.2 扫描 6927 `.js`/补 29 文件；v9.3 仅扫 1731 `.js`/补 4——spawn 位点 139/197 已迁 `.mjs`（Windows 黑框回归）。
  - 补丁 10（installedPackageNeedsOpenClawPeerLinkRepair）：v9.2 起上游已删（两版 dist 均无），系死补丁，无害。
- **适配（R72 已落地）**：三个扫描点（patchAsarBoundaryCheck 候选 / collectJsFilesRecursive / hasAsarBoundaryPatchMarker）
  扩展收 `.mjs`；`assertAsarBoundaryCoverage` 追加 peer-link `.mjs` 形态检查堵盲区；kernel-dist-patch.test.js 补 `.mjs` fixtures。
