# CryoBlue · Blue & Green

恢复原 **CryoBlue `#1A6FD0`**，以柔和绿色作少量点缀。`shared/design-tokens.css` 是应用的颜色、尺寸、字体与动效来源。

## 颜色职责

- `--brand` / `--brand-600`：原蓝色品牌基准，应用标识恢复原蓝青色阶。主操作、发送按钮、开关与滑块跟随主题强调色。
- `--accent-hover`：当前强调色的按压/悬浮状态；按钮前景色根据对比度自动选择深色或白色。
- `--accent`：主题的文字、链接与轮廓强调色。默认浅色用原蓝色，深色用同色系亮阶，保证在深底上易读。主题包可修改此色。
- `--bg` / `--bg-secondary` / `--bg-elevated`：阅读、导航与浮层分层；使用低彩度表面，避免整页高饱和蓝色。
- `--accent-2`：浅色为柔和叶绿 `#218363`，深色为 `#71C6A3`，用于就绪状态与辅助信息。红与黄继续表示危险、警告，绿色点缀不冒充成功提示。

## 控件与图标

常规按钮采用 34px 最小高度，密排行保留小尺寸；文字增大时按钮允许自然增高。图标按钮默认 32px 点击区，触控指针使用至少 40px。禁用、悬浮、按压与键盘焦点分别提供反馈；按压轻缩放，并服从减少动态效果设置。

`icons.ts` 的 CryoIcons 使用 24×24 网格、统一 `--icon-stroke: 1.75`、圆端点与圆连接。设置导航、工作区和主题编辑控件共用此源。装饰图标隐藏于辅助技术，图标按钮由文字、`aria-label` 或标题提供名称。保留供应商标识与用户自选工作区图标的语义。

## 主题与弹层

外观页只有一个“主题”模块，包含配对深浅预览、浅色/深色/跟随系统、微调、保存、导入与导出。两种配色独立保留；缺失的一种回退到对应默认配色。全局排版与元素几何设置跨两种配色共享。

模型能力编辑使用原生 `dialog.showModal()` 顶层，蒙版覆盖完整视口，不受滚动容器与父级位移裁剪；支持关闭、Esc、外点取消、焦点约束和连续退场。Theme Studio 有显式关闭按钮，关闭会撤销当前编辑预览。

消息功能按钮位于正文下方独立行，预留高度，悬浮只改变可见性，不覆盖正文、不造成布局跳动。键盘聚焦与触控均可操作。

本规范更新了旧文档中的蓝青品牌描述；历史归档保留其原始记录。


## 内置主题

| 主题 | 方向 | 配套层次 |
|---|---|---|
| 默认 | 原蓝白、熟悉轻盈 | 默认系统表面、少量叶绿点缀 |
| 冰川 | 通透冰蓝 | 蓝白浅色、深海蓝暗色，14px 基准圆角 |
| 石墨 | 柔灰、克制专注 | 暖灰浅色、炭灰暗色，8px 基准圆角 |
| 苔原 | 草木绿、自然舒展 | 草木白浅色、森林暗色，16px 基准圆角 |

弹层、输入框、悬浮底、文字与边框由当前配色派生，避免只换背景却留下不协调的控件。所有内置配对均检查正文、次要文字与主按钮至少 4.5:1 对比度。
