# Theme Studio

在「设置 → 外观」调整配色、字体、字号、无级字重、行高及圆角。MiSans VF 与 Inter 用于界面，JetBrains Mono 用于代码；可随时恢复系统字体。数字输入保留小数，滑块同帧只提交最新值，Shift + 方向键更细、Alt + 方向键更快。

## 对话与控件的独立配色

“微调当前主题 → 对话与控件配色”可分别设置用户/助手气泡、双方文字、输入卡片、输入框、图标和控件边框。对应主题包字段为 `userBubble`、`assistantBubble`、`userText`、`assistantText`、`composer`、`input`、`icon`、`border`，分别放入深浅两套 palette；点击“继承”移除该角色的覆盖。这些配色跨会话生效。默认浅色外观保持纯白背景。

实时编辑器现在可点选用户/助手气泡、输入卡片、消息文字和图标。除位置、尺寸和颜色外，支持内外间距、实线/虚线/无边框，以及图标尺寸与线宽。单个元素仍使用 inspect 返回的真实 ID；跨会话的整体风格优先用语义配色。主题格式仍为 v1，旧包未包含的新字段会继承默认值。

## 调整单个元素

点击「在软件中点选并调整元素」，再点击编辑器里的「选择界面元素」。点选不会执行原按钮动作。控件可以在原页面中移动、缩放，也可输入精确数值。

- 布局：水平/垂直位置、宽高、内边距、层级。
- 外观：圆角、边框宽度和颜色、背景、不透明度。
- 文字：大小、无级字重、字形、对齐及颜色。

拖动时 Shift 对齐 8px 网格，Alt 降低移动速度。编辑器提供 30 步撤销/重做、单元素重置和整个预览撤销。按 Esc 撤销预览；Ctrl+Alt+0 恢复默认外观。编辑器与恢复入口本身不参与主题定制。

自定义值以注册控件和页面范围保存，不包含任意选择器、HTML、脚本、远程资源或账户数据。位置不超过 ±600px，尺寸、字重和透明度各有明确范围。主题包导入上限 64KiB，导出包含独立控件设置。方案库最多保存 20 个命名方案，也可删除和再次导入。

## 主题包字段与自由度

主题包仍为 `format: "cryoclaw-theme"` / `version: 1`，新增字段全部可选，旧包可直接导入，缺省即保持现有观感：

- 顶层 `description`：不超过 120 字的一句话，导入后显示在主题卡上，导出时一并写入。
- `appearance.density`：0.9–1.1 的间距系数，按比例缩放 `--spacer-*` 阶梯；1 为现状。
- `appearance.shadow`：`none` / `soft` / `default` / `strong`，映射 `--shadow-xs…xl` 与弹窗阴影强度；`default` 为现状。
- `appearance.borderWidth`：0–2 的 `--hairline` / `--hairline-strong` 粗细；1 为现状。

「微调当前主题」里可直接调整主题描述、间距密度、阴影强度与边框粗细，实时预览并随“保存到主题库”持久化。所有字段都在 `appearance-profile.ts` 归一化时有界校验；主题包依旧不能携带任意 CSS、脚本、路径或远程资源。

## 让 Agent 生成主题

应用内置 `cryoclaw-theme-studio` 技能及设计提示模板。入口改成填空式 brief：风格意象（必填）、主色、辅色、明暗偏好、圆角倾向、排版偏好、必须保留、希望避免、补充要求；三个预设可一键填充整份模板，仍可逐项修改。风格意象为空或颜色以 `#` 开头但不是合法 3/6 位十六进制时，生成按钮禁用并给出提示。

可附最多 4 张参考图（点击选择或拖入，单张 ≤4 MB，dataUrl 缩略图可移除）。生成时图片作为消息附件随设计提示一起发出，只要求 Agent 提取配色、明暗层次与质感，不复制参考图中的文字、品牌或布局；无图时不发送附件。原有对话草稿与附件不受影响。

技能先读取当前主题与可用元素标识，按模板生成结构化 JSON，再调用桌面实时接口。Agent 只能发起预览；预览 60 秒后自动恢复。用户点击「保留主题」才保存，也可撤销或继续用可视化编辑器修改。

开发契约为本机控制服务 `POST /ui/theme`，操作只有 `inspect`、`preview`、`restore`。沿用本机随机 Bearer 认证，限制请求/响应大小，并通过受信渲染器回执确认应用结果。技能 helper 私下读取控制端口与令牌，不输出令牌。可执行运行时由 Gateway 的 `CRYOCLAW_NODE_BIN` 提供，无需用户另外安装 Node。

打包与内核更新均解包 `node_modules/openclaw/skills`。Gateway 的 `OPENCLAW_BUNDLED_SKILLS_DIR` 指向真实目录，使技能发现和脚本执行都能正常工作。

## 验证

`scripts/theme-studio-cdp-smoke.js` 验证原生技能发现、真实 helper 调用、API 预览、元素点选、精确输入、撤销/重做、Esc、图片缩略图、文件卡片和拖入提示。`scripts/theme-agent-cdp-smoke.js` 覆盖填空 brief、预设填充、参考图缩略图与附件发送、原草稿/附件保留；`scripts/imported-theme-cdp-smoke.js` 覆盖拖放导入、描述显示、density/shadow/borderWidth 实际应用以及非法/超限导入保留原主题。`scripts/appearance-cdp-smoke.js` 验证字体离线加载、小数字重轴、精细键盘步进、同帧合并、系统恢复及窄屏布局。


## 配对主题与品牌色

外观页的主题、方案库、配色与圆角已合并为一个“主题”模块。浅色、深色、跟随系统在同一套主题内切换，两种配色独立保存；旧主题缺失的配色回退默认。内置默认、冰川、石墨、苔原均提供深浅预览。主题 JSON v1 向后兼容，新增有界 `palettes.light` / `palettes.dark`（含辅助色 `secondary`） 和当前编辑的 `paletteMode`；主题包仍不可携带任意 CSS、脚本、路径或远程资源。

根据用户最新选择，恢复原 CryoBlue 蓝色并增加柔和绿色点缀；主操作跟随主题强调色，前景色自动保证可读性。参见 [视觉体系](VISUAL-SYSTEM.md)。实时编辑器右上角提供关闭按钮，关闭与 Esc 一样撤销当前编辑预览；“保留主题”才持久保存。


## 外观页的 Agent 入口

“主题 → 让 Agent 设计主题”提供结构化填空 brief、三个风格预设、参考图上传、预览方式和“保留现有字体与布局”开关。点击“让 Agent 生成并预览”后先通过原生 `skills.status` 检查主题技能；可用时将填空内容、参考图数量与标准化参考主题发送到当前对话。发送采用独立消息参数，保留输入框中已有草稿和附件；对话繁忙时沿用现有队列。连接、当前会话或页面变化时停止发送；技能不可用时明确提示。

提示词要求配套深浅主题、先 inspect 真实注册元素、检查对比度、按填空字段设计、正确使用 `description` / `density` / `shadow` / `borderWidth` 有界字段、参考图只作配色与质感参考且不复制文字/品牌/布局、写入 JSON 主题包并调用捆绑 helper 验证预览。由用户点击“保留主题”后应用，Agent 主题会以独立名字、描述与来源标记加入主题库；同名保留原主题，主题库满时仍保留已应用外观并提示导出。不会因为打开表单而调用模型。

## 导入与导出

主题模块支持文件选择与拖放两种导入：把 `.json` 主题包拖到“主题”模块上会高亮提示，松手即导入；也保留了“导入主题包”按钮。超过 64 KiB、非 JSON、格式或版本不符时拒绝导入，当前主题与既有主题库保持不变，错误同时走页面 message-box 与全局 toast；导入成功后给出明确 toast。导入后直接加入带来源标识和描述的预览卡片；同名自动编号，长名称省略显示并保留完整标题，多语言与 emoji 不截断成无效字符。兼容未声明模式的旧主题和只提供 `palettes` 的配对主题；缺失的另一版显示默认配色提示。库满、无效 JSON、超限或无法写入时保留当前主题与既有库数据。

导出使用主题名生成安全文件名（过滤 `\ / : * ? " < > |` 与控制字符，中文与 emoji 保留），内容包含名称、描述、深浅配色、有界新字段与单元素设置；导出成功同样给出 toast。导入使用可撤销的临时预览条，默认 60 秒恢复。预览条不参与元素自定义，即使导入布局隐藏了设置面板也可撤销；重置主题会清除正在预览的元素位置。点击“保存设置”或“保留主题”才应用，主题库导入与应用状态分别显示。


## 技能错误恢复

设计入口最多自动检查 3 次；对于被禁用的内置主题技能，仅尝试一次原生启用操作，再验证状态。进度与最终原因可见，失败保留设计描述并提供“重试并生成”；页面、连接或会话变化时停止后续操作。不会自动安装外部包或改动账户信息。

helper 对瞬时本地连接/服务故障最多重试一次，每次重新读取私有控制端点；对格式校验错误立即返回，不盲目重试。文件读取有大小上限，配置错误信息不包含令牌内容，支持 UTF-8 BOM。Agent 提示另要求最多 3 轮诊断、修正自己的临时主题包/调用方式并重新验证；仍失败就保留主题包、说明失败环节和下一步。
