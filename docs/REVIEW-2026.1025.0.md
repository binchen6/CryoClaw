# 2026.1025.0 · 看板、对话与安装体验验收

本版保留 OpenClaw 2026.10.6、Node 24.22.1、Electron 43.8.3 和物理网关目录，集中改造前端布局、功能入口、控件分组、看板手势和首屏/长历史渲染。以下分别记录设计结果、同机性能对照和已完成的验证；安装版与发布结果在最终补记中单独确认。

## 布局、样式与功能入口

- 主导航从纯图标改为 68px 图标 + 简短文字标签，明确对话、看板、任务、工作空间、扩展和设置。会话栏把新建对话从头部小图标改为全宽主按钮，低频更多/归档操作保留在原位。
- 上下文栏增强当前会话标题，显示已绑定工作区，导出与会话信息归入右侧操作组。窄窗自动隐藏工作区副标题，保留主标题与操作。
- 空对话以“从一句话，到完成的工作”为主标题，四类入口分别对应理解项目、自动执行、审查改动和整理文件；每张卡有用途标题、具体提示和方向指示，不再只展示四个长句按钮。
- 输入区左侧保留附件、模型和执行权限，右侧放置分支历史、额度与发送。权限文案统一为逐步询问、智能审批、全部允许，不再使用含糊的“请求批准/完全同意”。分支弹层在右侧打开时向右收束，避免溢出。上下文记忆改为输入卡内部的“标签 + 细轨道 + 百分比”状态行，聚焦改为 1px 淡蓝边和轻量状态光；toast 按输入区实际高度连续避让。
- 看板移除重复元信息栏和重复设计入口。标签右键仅保留编辑详情与删除；更多菜单承载模块库。常驻铅笔统一模型制作、布局整理和元素微调，输入框出现时自然上移，再点铅笔退出并保留草稿。专注模式避让原生标题栏，卡片 chrome 提供单卡刷新，其他 iframe 与布局不变。

## 懒加载与生命周期

- 设置、看板、任务、工作区、扩展和首次向导按路由加载；默认对话不再同步解析这些视图。路由切换立即响应，模块加载期间显示轻量进度态，失败提供重试，不显示空白页。
- 悬停或聚焦导航同时预取对应模块与既有页面数据。设置离开清理由设置模块自行注册，任务和扩展继续沿用原有 leave hook，避免懒加载后遗留定时器或监听器。
- 中英文各 1,779 个词条继续由一致性测试锁定。浏览器首次只加载当前语言；`setLocale` 保持同步切换契约，未加载语言需先调用 `loadLocale`，Node 测试环境保留双语同步测试能力。

## 插件、技能与完整动效

- 内置看板插件升至 1.3.0。`motion.animate` 支持取消、完成等待、隐藏时暂停和恢复；`viewport` 把真实卡片宽高和合并后的 resize 通知交给模块，21 个示例按内容连续重排，不再使用固定 1600×900 画布。
- 随手记、行程清单/备注、节奏、配色等本机状态在 resize、全屏和还原中保留。模块预览使用独立受限文档与明确示例数据；A 股在原源失败时使用严格限定的备用源，并展示实际来源、行情时间和缓存状态。
- 全屏使用浏览器顶层且保留同一个 iframe。动画期间不再把滚动容器改成 `overflow:visible`；反向展开不退出顶层，Popover 自动聚焦定向到卡片本身，回落使用原始几何并即时恢复滚动位置。21 个模块 × 4 档尺寸共 84 项通过；87 个普通、快速和减少动态效果周期通过。证据：`.cache/dashboard-responsive/2026-10-25T16-01-57-389Z/report.json`、`.cache/dashboard-morph-all-final-3/report.json`。
- 内置技能的 runtime/design 指南同步真实尺寸、自由布局、元素选择和动效规则。完整看板 E2E 覆盖真实音频频谱、canvas 不重复分配位图、归档恢复、任务边界和置顶关闭：`out/dashboard-v2-review/2026-10-25T16-05-17-645Z/report.json`。

## 录屏与最终代码审查

- 本地 60.9 秒看板录屏只在本机分析，未上传。针对可见问题：切换改为旧/新画布交叉过渡并保留最新代次；创建看板提供可替换默认名称与下一步引导；首次扫描按钮、弱对比文本、Hero 高度和底部内容留白修正。永久删除继续要求明确确认，不提供无法恢复状态的假“撤销”。
- 大卡片拖到多个小卡片时，释放后按所有受影响卡片的当前/目标矩形执行 FLIP，保留 iframe 文档与真实布局顺序；键盘整理和“整理看板”复用同一路径。新增 12 列大卡片拖到三张 4 列卡片中的实际指针验收，要求移动阶段零整页 render、松手顺序正确且 FLIP 确实发生。
- 代码审查修复：导航模块晚到不抢回用户已离开的视图；图标轨不再用闭包中的旧 `cryoclawView` 跳过快速返回；应用级与看板级 View Transition 互斥，避免嵌套触发 `InvalidStateError`；看板切换与展开动画互斥；相对时间用负数表示过去并跟随语言；后台菜单退出有界且幂等收尾。快速切换使用真实 `transitionView` 点击路径验证。
- 生命周期审查：同轮只读 ticker handler 并发完成，轮次仍不重入；Mistral 仅在实际默认解析为纯 ESM 时删除重复 `src`，保留生产 `esm` 和包元数据；启动测量区分 `healthz`/`readyz` 并记录 `quitMs`，CPU 采样覆盖完整启动窗口，日志路径修正为 `logs/app.log`，PowerShell 仅清理本次进程树。差分下载已高度复用，但更新安装仍需完整解压；不在本版冒险重写更新协议。
