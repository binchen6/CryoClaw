## 补充优化

- 工作空间：本地只读路径上下文、目录真实预读、按连接/路径/隐藏项隔离的30秒内存缓存，失败不缓存，强刷与写入失效。
- 用量：按连接/日期范围缓存与去重，切回保留范围，旧连接不能污染新数据。
- 语音：三路状态共享预读，短失败退避，明确刷新，修改后失效并强刷，断连不再假报保存成功。
