FEATURES

为「好用」做的系统性重设计

在 OneClaw 之上重构：视觉、设置架构、流式渲染、模型管理、更新链路，全部重来一遍。

丝滑流式渲染

逐帧纯文本流式 + 终态一次性排版，消除逐帧全量 markdown 的 O(n²) 卡顿；折叠区懒渲染，长对话也稳。

冰蓝设计体系

TraeWork design token + cc-* 原语组件，浅色/暗色双主题，lucide 统一图标。干净、克制、工程感。

双通道自动更新

应用本体走 GitHub Releases 差分下载、静默换装；内核能力走独立升级器，可升级、可回滚、有更新日志。

模型管理重设计

provider 分组、拖拽排序、fallback 链、能力徽标（思考/上下文/图像）、密钥有效性探测，四处选择器联动。

思考强度全档位

按模型能力正确开放思考档位 —— Kimi K3 支持 low / medium / high / xhigh / max，不再被误限为开/关。

多渠道远程控制

飞书 / 企业微信 / 钉钉 / QQ / 微信 —— 设置里扫码绑定，让 AI 在你团队的 IM 里干活。

安全与隐私

API Key 只存本机；全部 IPC 过 sender guard；日志统一归集并脱敏；一键导出诊断包（自动脱敏）。

插件生态

设置页管理已安装插件（启停/卸载），内置 ClawHub 插件市场，搜索、一键安装，告别命令行。

会话回放与分支

压缩回放点任意 rewind / fork 出新会话；消息引用、失败重发、Ctrl+N / Ctrl+L 快捷键，全流程顺手。
