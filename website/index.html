开始之前，
你可能想知道。

需要先安装 OpenClaw 或 Node.js 吗？

不需要。CryoClaw 安装包已经内置 Node.js 运行时和 OpenClaw 内核。完成安装后，按引导连接模型服务即可。

CryoClaw 免费吗？模型费用怎么算？

CryoClaw 以 AGPL-3.0 协议开源。你需要使用自己的模型服务或本地模型；云端模型的用量、价格和订阅由对应服务商决定。

文件和对话会上传到哪里？

工作空间与配置保存在本机。使用云端模型时，对话及任务需要的内容会发往你选择的服务商；浏览器、插件和消息渠道按各自的配置与权限运行。

下载慢或中断了，怎么办？

可使用支持断点续传的下载器继续本站下载，也可切换到 GitHub 原始文件或第三方备用镜像。安装前可展开下载区的 SHA-256 校验信息。

页面里的看板和交付内容是真的吗？

产品截图来自真实软件页面组件，任务和文件使用虚构示例；看板区域是功能示意。实际内容与完成情况取决于你的模型、权限和任务配置，宣传片经过剪辑，不代表实际执行耗时。
