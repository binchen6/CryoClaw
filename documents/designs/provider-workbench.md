# CryoClaw 模型设置工作台

## 目标
依据本次三张模型设置参考图重构信息架构：供应商目录、单供应商详情、添加供应商。白色留白、柔灰圆角供应商行、轻边界表单、可换行预设 chips、底部操作区；保留 MiSans / CryoBlue / 当前主题 tokens。

## 交互和兼容
- 目录先呈现订阅与 API 供应商；主模型概览紧凑，角色、备用模型、智能体映射和自定义分组移入可展开高级区，不删除能力。
- 供应商行整行键盘可操作，展示标识、协议、模型数量、默认状态；搜索支持模型/供应商，命中后进入详情仍保留全部模型。
- 详情显示供应商标识、实际配置协议、端点与安全密钥编辑；不伪造后端不支持的供应商重命名，不把代理端点当成可随意改写的普通 URL。模型 ID / 上下文 / 显示名以紧凑行呈现，真实高级编辑、排序、分组、同步和用量入口仍可用。
- 添加页使用现有预设、目录和 OAuth/验证/配置补丁链路；不同供应商预设不能残留前一个草稿密钥。取消清理秘密，保存失败保留可重试状态。
- 忙碌时禁用返回/切换，避免在异步保存中丢弃草稿；供应商消失时回退目录，不渲染失效详情。
- 不新增依赖，不更改配置 schema，不把脱敏值当作新密钥，不直接覆盖配置文件。修复 keySaving 与 config.patch busy 锁冲突。

## 图标与同级过渡
- 预置供应商图标参考 [Simple Icons](https://github.com/simple-icons/simple-icons) 与 [Lobe Icons](https://github.com/lobehub/lobe-icons) 的公开矢量源，重新绘制为 24×24 单色线性几何；保留品牌核心轮廓，减少碎细节，确保 16px 可辨识，不发起运行时图片请求。
- Google 使用 G 轮廓，Z.ai 使用 Z，MiniMax 使用竖条节奏，火山引擎使用斜切层次，Moonshot 使用轨道弧线；其他品牌保留可识别轮廓并统一描边与留白。未知自定义供应商仍显示名称首字母。
- 目录、详情、添加之间采用与全站一致的短距离方向过渡：进入向前、返回向后，只使用 opacity/transform，服从 reduced-motion，不延迟数据或按钮操作。

## 验证
三层导航、预设切换、添加/返回、默认模型/同步/高级编辑入口、密钥保存与失败/重复提交、列表筛选、800/1440 宽度和 light/dark、无水平溢出与无 renderer exceptions；完整构建与既有测试。
