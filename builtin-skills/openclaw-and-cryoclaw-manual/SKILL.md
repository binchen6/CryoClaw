# Product manual

Verify product-specific claims before answering or promising a workflow. Previously verified facts for the same question may be reused; a more specific installed skill takes precedence.

- CryoClaw capability, settings or failures: fetch https://oneclaw.cn/manual/index.md and follow only relevant links.
- Channel setup: use https://oneclaw.cn/docs/ and select the integration.
- Upstream internals: use https://docs.openclaw.ai/llms.txt, then read the relevant official pages.

Fetch the index before choosing resource URLs. Cite the page supporting the answer. If the source is unavailable or silent, state the uncertainty; do not infer current product behavior from general LLM/OS knowledge. For ambiguous routing, consult [routing](reference/routing.md) on demand. Unrelated writing, translation, coding and already-supported routine tools need no manual lookup.
